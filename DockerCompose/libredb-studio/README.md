# LibreDB Studio

Работа подготовлена по [заданию преподавателя](https://github.com/rurewa/imfua/blob/main/content/Docker/DockerCompose/LibreDB_Studio.md) с официальным образом `ghcr.io/libredb/libredb-studio:latest`. Используется режим автоматической локальной конфигурации, рабочие данные размещаются в именованном томе.

## Запуск

```powershell
docker compose config
docker compose up -d
```

После успешного старта интерфейс должен быть доступен на <http://localhost:3000>. Сгенерированные приложением учётные данные нельзя добавлять в README или скриншоты. Остановка: `docker compose stop`.
