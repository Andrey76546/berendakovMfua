## Обновление Ubuntu WSL 2

- Выполнено обновление индекса пакетов командой `apt update`.
- Обычной командой `apt upgrade` обновлено **182 пакета**, включая **132 обновления безопасности**.
- Новые пакеты не устанавливались, пакеты не удалялись.
- Два пакета остались отложенными из-за поэтапного распространения обновлений: `python3-software-properties` и `software-properties-common`.
- Проверки `dpkg --audit` и `apt-get check` завершились без ошибок.
- Ubuntu запускается, Systemd работает, сбойных служб не обнаружено.
- Перезагрузка Windows не выполнялась и не требуется.

## Итог

Обязательное программное обеспечение из README проверено. Отсутствовавший редактор Micro установлен. Доступные штатные обновления Ubuntu применены без удаления пакетов и без ошибок проверки целостности.
